# 水やりゲーム

バイオリンの音を伸ばすと、ジョウロが出てきて種に水をかけ、花が育つゲームです。ブラウザで開いて遊びます。

公開先: https://ngmt4amtk-web.github.io/violin-mizuyari/

最初の画面（index.html）でレベルを選びます。

- レベル1「のばす」（app.html）: 音を伸ばして、花を1つ咲かせる。
- レベル2「ゆび 1つ」（yubi.html?lv=2）: 弦と、指（0・1・2）を1つ選び、タネを1つ咲かせる。
- レベル3「ゆび 0〜2」（yubi.html?lv=3）: 0・1・2の3つのタネを咲かせる。
- レベル4「ゆび 0〜3」（yubi.html?lv=4）: 0〜3の4つのタネを咲かせる。
- レベル5「ゆび 0〜4」（yubi.html?lv=5。?lv を付けない yubi.html も同じ）: 前のレベル2と同じ、0〜4の5つのタネ。
- あそび「まめのき」（mame.html）: 制限時間の中で、豆の木をどこまで伸ばせるか遊ぶ。
- あそび「かいほうげんの タネ」（kaihou.html）: 4本の開放弦に1つずつ埋まったタネを、制限時間の中で全部咲かせる。最初の画面には載せていないので、https://ngmt4amtk-web.github.io/violin-mizuyari/kaihou.html を直接開きます。

下の「あそびかた（レベル2 ゆびのタネ）」はレベル5の説明です。レベル2〜4の違いは「レベル分けと音程のアドバイス」に書きました。

## あそびかた（レベル1）

1. 開くとすぐ、マイクを使ってよいかブラウザに聞かれるので、許可します。「はじめる」を押さなくても聞き始めます。ブラウザが「画面に触れるまで音の処理を始めない」時は、ボタンが「はじめる」のまま残ります。その時は、画面のどこかに触れるか、ボタンを押すと始まります。
2. 音を伸ばします。音が聞こえたら、すぐに植物の左側にジョウロが立った形で出ます。音が0.5秒（初期値）続いたところでジョウロが傾き、0.25秒ほど後から水の粒が落ち始めます。音が続くあいだは水が落ち続け、止めるとジョウロは下がります（一度水を出したジョウロは、すぐ止めても1.5秒ほどは水をかけて見せます。その間に次の音が始まった時は、水を止めて立てたまま待ち、その音が1秒続いたらまた傾けます）。1秒に届く前に音が止まった時は、水を出さずに0.6秒ほどで下がります。
3. 伸ばした時間は秒で数え、途中で止めても合計に残ります。続けて弾く必要はありません。上の目盛りに「4 / 10 びょう」のように出ます。合計5秒（初期値。設定で3〜60秒に変えられます）で花が咲き、「さいたね！」と出て、その回はおしまいです。咲いた後に弾いた音は数えません。
4. 1秒に届かなかった音は測りません。目盛りに足さず、水も出ません。1秒続いた音は、その最初の1秒も含めて足します。トレモロ（弓を細かく往復させる弾き方）も数えません。トレモロの間はジョウロを出さず、「のばしてね」とだけ出します。ただし、トレモロと分かるまでの弾き始めの一瞬（合成した音で約0.2秒）は、ジョウロが出かけてすぐ下がります。
5. 育つ様子は動きで見せます。音が聞こえたら、1秒に届く前から植物が大きく揺れ、種はぷるぷる震え、音符がふわふわ上がります（数え方は変わりません。1秒に届かない音は、揺れても数えません）。水が落ちる所には、しぶきが出ます。音がない時も、植物はゆっくり揺れています。0.5秒たまるごとに植物が「ぽよん」と弾みます。芽・茎・つぼみの段階の中でも、0.5秒ごとに背がぴょこっと伸びます（その段階の大きさの8割から10割へ）。次の段階へ進んだ時は、土からニョキッと伸び上がり、根元から色の粒がはじけます。どれも見た目だけで、数え方は変えていません。端末で「視差効果を減らす」（動きを減らす設定）を入れている時は、この動きを出しません。
6. 咲いた後は、ボタンが「もういちど」に変わります。押すと種から始め直します。咲いた後にマイクや音の処理が止まっていても、このボタン1つで聞き直します。

タブを裏に回したり画面を消したりして音の処理が止まると、ボタンが「つづける」に変わります。押すと再開します。マイクが外れた時は「はじめる」に戻ります。どちらの場合も、それまでに貯めた秒数と水やりの回数は残り、途中だった音は1秒からやり直しです。

設定は、そのブラウザの中に残ります。咲いた花の数は数えず、残しもしません（前の版が残した咲いた数は、開いた時に消します）。録音はしません。音のデータを保存したり、外へ送ったりもしません。

## あそびかた（レベル2 ゆびのタネ）

1. 「どの げんで あそぶ？」で、ソせん・レせん・ラせん・ミせんのどれかを押します。押すとマイクを使い始めます。
2. 土に 0〜4 の番号の札が付いたタネが5つ並びます。札の色は弦の色です（ソ線は青、レ線はオレンジ、ラ線は赤、ミ線は緑）。
3. 好きな指で音を伸ばします。音の高さに合うタネの札が光り、1秒続くとジョウロがそのタネの上に来て水をかけます。札のまわりの輪が、育ちぐあいに合わせて弦の色で埋まります。
4. 1つのタネは合計5秒（初期値）で咲きます。どの順で咲かせてもかまいません。5つ全部咲くと「ぜんぶ さいたね！」と出て、その回はおしまいです。「もういちど」で同じ弦の最初から遊べます。「げんを かえる」で別の弦を選ぶと最初からになり、同じ弦を選ぶと続きから遊べます（間違えて押した時のため）。
5. ほかの弦の音を弾くと「いまのは レせんの 0」のように出ます。どの指の音とも離れた高さの時は「どの タネかな？」と出ます。どちらも水は出ません。

数え方の決まりはレベル1と同じです。1秒に届かない音は数えず、トレモロも数えません。1秒続いた音は最初の1秒も含めて足します。違う指の音に変わったら、その音でまた1秒から数えます。すでに咲いたタネの音を弾くと「◯は もう さいたよ」と出て、水は出ません。

### 指の音の決め方

候補は、4本の弦それぞれの 0〜4 の指の音（1ポジション）です。1は開放弦の全音上、3は完全4度上、4は完全5度上（となりの開放弦と同じ高さ）です。2は、弦ごとに高い2（長3度上。ラ線ならド♯）と低い2（短3度上。ラ線ならド）を設定で選べます。初期値は全部の弦で高い2です。

弾いた音にいちばん近い候補を探し、それが選んだ弦の指ならそのタネに水をかけます。高さは直近0.12秒の真ん中の値で見るので、弾き始めの一瞬のゆれで別のタネへ飛びません。ラ線の4とミ線の開放のように同じ高さが2つの弦にある時は、選んだ弦の指とみなします。ほかの弦どうしで重なる時は、開放弦の名前で出します。この決め方は、教室のアプリ「ゆびいろ」に合わせました。

このため、4のタネは、となりの開放弦（ラ線を選んだ時のミ線の開放など）でも育ちます。音の高さだけでは、4の指か開放弦かを見分けられません。

いちばん近い候補からのずれが大きすぎる音は、どのタネにもしません。どこまで許すかは設定の「音の高さの見分け」で、ゆるめ（90セント。初期値）・ふつう（60セント）・きびしめ（40セント）から選びます。セントは音の高さの差の単位で、半音が100セントです。たとえば高い2の設定でドのナチュラルを弾くと、シからもド♯からも100セント離れているので、どのタネにもなりません。

### レベル2の設定（右下の歯車）

- タネ1つが咲くまでの秒数: 3〜60秒（初期値5秒）。
- 2の指: 弦ごとに高い2か低い2。
- 音の高さの見分け: ゆるめ・ふつう・きびしめ。
- 基準のラ: 440〜443Hz（初期値442Hz）。
- 水が出るまでの秒数・音の大きさのしきい値・トレモロの見分け: レベル1と同じ値を使います。どちらで変えても、もう一方に効きます。

## 音の見分け方（両方のレベルで共通）

10ミリ秒ごとにマイクの音を調べ、次の3つがそろった時間だけを「伸ばしている音」として数えます。

- 音が十分に大きい。大きさの基準（しきい値）は設定で変えられます。
- 音の高さがはっきりしている。こすれる雑音や話し声の一部はここで外れます。
- トレモロではない。

トレモロは、弓を返すたびに音量が一瞬下がることで見分けます。音量が6dB（デシベル。音の大きさの差の単位で、6dBは振れ幅がおよそ半分）以上落ちて戻る谷が、0.7秒の中に2回以上あればトレモロとみなします。ゆっくり弓を返しながらの長い音は、谷が1回ずつしか来ないので数えます。

ビブラートでも音量は少し揺れます。音の高さが揺れている間はビブラートとみなし、谷の基準を3dB深くして、トレモロと取り違えにくくしています。

トレモロと分かるまでには少し遅れが出ます。そこで、伸ばした時間はいったん仮置きにして、約0.9秒たってから確定します。トレモロと分かった時は、仮置きの分だけを取り消します。花は確定した分で咲くので、合計が開花の秒数に届いてから咲くまでに約0.9秒かかります。

## 設定（レベル1。右下の歯車）

大人が触る画面です。

- 開花までの秒数: 3〜60秒（初期値5秒）。
- 水が出るまでの秒数: 0.5〜2.0秒（初期値0.5秒）。この秒数は、数え始める長さでもあります（これより短い音は数えません）。
- 音の大きさのしきい値: −70〜−20dB（初期値−55dB）。今の音量のメーターが出ます。弾いている時にメーターが赤い線を越え、弾いていない時に越えない位置に合わせます。部屋がうるさい時は右へ、音が小さくて反応しない時は左へ動かします。
- トレモロの見分け: きびしめ・ふつう・ゆるめ（初期値ふつう）。トレモロが数えられてしまう時は「きびしめ」に、ビブラートや普通の長い音が数えられない時は「ゆるめ」にします。

初期値の移り変わり: 水の秒数ははじめ依頼の言葉（1秒で水）に合わせて1.0秒、開花の秒数ははじめ30秒でした。本人の「デフォ10秒で良いや」（2026-11-04）で開花を10秒にし、同じ日の午後の「しきい値デフォルト低くして、開花まで5秒がデフォルト、0.5秒で水が出るようにしよう」で、開花5秒（レベル2のタネも15秒から5秒）・水0.5秒・しきい値−55dBにしました。しきい値をどこまで下げるかは指定がなかったので、10dB下げました。

前の版が保存した値のうち、その版の初期値と同じもの（開花10秒・最初の版の30秒、水1.0秒、しきい値−45dB、レベル2のタネ15秒）は、選んだ値か初期値のままかを見分けられないので、開いた時に今の初期値へ読み替えます。前の版のレベル2は、弦を選ぶだけで水の秒数やしきい値まで保存していたので、多くの端末に前の初期値が残っているためです。それ以外の値（20秒など）は、そのまま使います。今の版で保存した値には印（defV・v が3）を付けているので、10秒などを選んでも、そのまま残ります。

## 絵の差し替え

今の絵9枚は、2026-11-04 に Codex の画像生成で作りました（本人「codexに画像生成とかさせて良い感じに」）。生成したままの絵は images_原本/ にあり、使ったプロンプトは images_原本/生成メモ.md にあります。images/ の絵は、試験/shiage.py で原本から仕上げた物です。植物は透明な余白を切り、根元が左右の真ん中に来るようにしています。ジョウロは、注ぎ口の先が水の粒の出る位置に来るよう置き直しています。土は、全部が土の横長の帯に切り出しています。作り直す時は、原本を差し替えてから uv run --with pillow python 試験/shiage.py images_原本 images と打ちます。

images フォルダに次の名前の PNG を置くと、その絵が使われます。置いていない絵は、仮の図形のまま表示されます。背景は透明にしてください。ファイルを置いたら、ページを読み込み直します。絵の読み込みが遅い時は、読み込みが終わるまで仮の図形が出ます。

- soil.png: 土の山。横長（横がおよそ4、縦が1）。枠いっぱいに広げて表示します。
- seed.png: 種。横長（横3.3、縦1）。下の方が土に隠れます。
- sprout.png: 芽。横1.6、縦1。
- stem.png: 茎と葉。正方形。
- bud.png: つぼみ。横0.85、縦1。
- flower.png: 咲いた花。横0.63、縦1。
- can.png: ジョウロ。ほぼ正方形。注ぎ口を右に向けて描きます。植物の左に置き、音が聞こえた時はそのまま、水を出す時は右へ傾けて表示します。今の絵は注ぎ口が右上を向いているので、絵がある時だけ水の粒の出る位置を変えています（app.html と yubi.src.html の「#canBox.img-ok ~ #drops」）。絵を替えて注ぎ口の位置が変わった時は、試験/shiage.py が出す drops_left_top_pct の値に、この2か所を直します。
- drop.png: 水の粒。縦長の小さな絵。
- bg.png: 背景（なくてもよい）。画面いっぱいに広げて表示します。

植物の絵は、根元が絵の下の端の中央に来るように描きます。縦横の比が違っても、枠の中に収まるよう縮めて表示します。

## 確かめたこと（2026-11-04）

合成した音（コンピュータで作ったバイオリンに似た音）で確かめました。子どもの実際の音では、まだ確かめていません。

見分ける仕組みだけを動かす試験で、27通りの音が全部、期待どおりの結果になりました。この試験は仕組みだけを動かすので、30秒を超えて弾き続けた時の数え方も確かめています（アプリでは、1回咲いた所で数えるのをやめます）。

- 3秒伸ばすと水1回、合計約3秒。低いソ（196Hz）と高いミ（1319Hz）でも同じ。
- 35秒伸ばすと花が1回咲き、残り約5秒が次の花へ繰り越される。
- 1.3秒の音を5回弾くと水5回、合計約6.5秒。0.9秒の音を40回弾いても0秒（1秒に届かない音は数えない）。
- 1.5秒の音を21回弾くと、合計約31秒で花が1回咲く。
- 10秒の長い音で2秒ごとに弓を返しても、途切れずに数える。だんだん弱くする音も数える。
- トレモロ（1秒に4・6・8・10・12・16回、谷の深さ7〜60dB）は、どれも0秒。
- ビブラート（高さ±30〜40セント、音量±2〜3dB）は数える。
- 大きな雑音、小さすぎる音、無音は数えない。
- 29.85秒まで伸ばしてすぐトレモロにしても、花は咲かない。1.6秒伸ばしてからトレモロにすると、前の1秒あまりは残る。
- 25秒貯めた後で開花の秒数を10秒に下げると、続けて2回咲く（咲くのは、次に音の処理が動いた時。マイクが動いていれば0.01秒ほどで動く）。開花の秒数に0を渡しても止まらない。

Chrome に作り物のマイクを付け、合成した音を流してアプリ全体も動かしました。

- 38秒の長い音のあと、4秒の音: 1秒でジョウロが出て水が落ち、芽、茎、つぼみと育ち、合計30秒に届いて約0.9秒後に花が咲いた。「さいたね！」と「もういちど」が出て、ジョウロは下がり、咲いた後も続いた音は数えなかった。「もういちど」を押すと種に戻り、続く音を0秒から数え直した。咲いた後に音の処理を止めてから「もういちど」を押した時も、1回押すだけで聞き直した。
- 12秒のトレモロ: ずっと0秒のまま。ジョウロは出ず、「のばしてね」が出た。
- 1.3秒の音2つ、0.7秒の音、3秒の音、トレモロ3秒を続けて流した時: 水は3回、0.7秒の音とトレモロは数えなかった。

同じ作り物のマイクで、途中で音の処理を止める、「つづける」を押す、マイクが外れたことにする、「はじめる」を押す、の順に動かしました。止めるとジョウロが下がってボタンが「つづける」になり、押すと再開しました。マイクが外れるとボタンが「はじめる」に戻り、押すと貯めた秒数（約7.9秒）と水やりの回数（2回）を残したまま再開しました。

画面は、横長のタブレット（1180×820）、縦長のタブレット（768×1024）、スマホ（390×844）の大きさで、はみ出しや横スクロールがないことを確かめました。

試験の道具は「試験」フォルダにあります。このフォルダで node 試験/test.js detector.js と打つと、見分ける仕組みの27通りの試験が動きます。

### レベル2（2026-11-04）

合成した音で確かめました。基準のラは442Hzです。

見分ける仕組みの試験（node 試験/test2.js）で、18通りが全部期待どおりでした。

- ラ線の 0〜4 を3秒ずつ弾くと、それぞれのタネに約3秒ずつ入り、水は5回。
- 1の指を16秒弾くと、1のタネだけが咲く。5つとも16秒弾くと5つとも咲く。
- ラ線を選んでレ線の開放を弾くと、どのタネにも入らず「レ線の0」と聞こえたことになる。
- 高い2の設定でドのナチュラルを弾くと、どのタネにも入らない。低い2の設定ならドは2のタネに入り、ド♯は入らない。
- 0から1へ、弓を止めずに2秒ずつ移ると、それぞれのタネに約2秒ずつ入る。0と1を0.6秒ずつ交互に弾いても入らない（どれも1秒未満）。
- ビブラート（±30セント）、30セント高い音、440Hzで調弦した楽器の音（−8セント）は入る。きびしめで60セント高い音は入らない。
- 1の指のトレモロは入らない。14.9秒でトレモロにすると咲かない。

## 見分けにくい音（合成した音での境目）

1秒に6・8・10・12回のトレモロで、谷の深さを3〜8dBまで変えて試しました。

- ふつう: 谷6dB以下のトレモロは、伸ばした音として数えてしまいます。谷7dBは、1秒に10〜12回なら外せますが、6回では数え、8回では一部を数えます。谷8dB以上は全部外せます。
- きびしめ: 谷5dB以上のトレモロを外せます（1秒に8回と12回で試しました）。ただし、音量が±3dB揺れるビブラートも数えなくなります。
- ゆるめ: 試した中で外せたのは、谷10dBで1秒に12回のトレモロだけでした。1秒に8回だと谷10dBでも数えてしまいます。音量が±4dB揺れるビブラートも数えます。

本物のトレモロで谷が何dBになるかは測っていません。合成した音での結果です。
